酷得斯店铺登录助手（Windows）

作用：装在授权电脑上。OA 里点“立即登录”，这台电脑会用专用的 Chrome 窗口登录店铺；你在窗口里到平台后台提现。
店铺的登录状态（Cookie）只保存在这台电脑，不会上传到 OA。

安装
1. 电脑上需要有 Google Chrome（或 Edge）和 Node.js 20 以上。
2. 在 OA“店铺提现 → 授权电脑 → 生成绑定码”，拿到 8 位绑定码（10 分钟有效，只能用一次）。
3. 解压本文件夹，打开 PowerShell，运行：
   .\install.ps1 -Server https://你的OA地址 -Code 绑定码
4. 回到 OA 页面，这台电脑显示“在线”即成功。

日常
- 助手开机自动运行，没有界面；OA 页面上看状态。
- 本机查看：node %LOCALAPPDATA%\KudesiAssistant\app\versions\<版本号>\dist\cli.js status
- 日志：%LOCALAPPDATA%\KudesiAssistant\agent.log

卸载：.\uninstall.ps1   （加 -RemoveData 同时删除店铺登录状态）
说明：电脑被管理员在 OA 里“撤销”后，助手会自动停止并提示重新绑定。

在线升级
- 管理员在 OA“店铺提现 → 授权电脑”上传新版升级包，点“升级”或“全部升级”，助手下次连上 OA 时自动下载、校验、切换并重启。
- 新版本启动后两分钟内没能连上 OA，会自动退回旧版本，并在 OA 里显示“已回退”。
- 店铺窗口正在被使用时，助手会等当前请求办完再升级。
- 升级包只更新助手程序；启动器（launcher.js）和 Node 依赖只在安装时更新。遇到 OA 提示“需要重新运行安装脚本”时，请重新运行 install.ps1。
- 从 1.0.0 升到 1.1.0 需要手动重新运行一次 install.ps1（1.0.0 还没有自更新能力）。

远程协助（默认关闭）
- 作用：店铺窗口需要人工操作（拼多多滑块/短信验证等）而人不在这台电脑旁时，OA 里有权限的同事可以看到并操作“这家店铺的浏览器窗口”（只有这个窗口，看不到桌面和别的程序）。
- 需要两道同意：① OA 管理员在“店铺提现 → 授权电脑”里开启这台电脑的远程协助；② 电脑主人在本机允许：
    node %LOCALAPPDATA%\KudesiAssistant\app\versions\<版本号>\dist\cli.js remote prompt   （每次申请弹窗询问，30 秒内点“是”才同意；开启后的建议值）
    ... cli.js remote auto     （自动同意，适合无人值守的电脑）
    ... cli.js remote off      （不允许，默认值）；不带参数查看当前设置
- 每次协助有时限（管理员设置，默认 15 分钟，最长 60 分钟），店铺窗口关闭、网页关闭、OA 撤销电脑都会立即结束；谁、哪家店、多久都记入 OA 的操作日志。
- 页面跳到平台以外的网站时，画面会暂停、操作会被拒绝。
