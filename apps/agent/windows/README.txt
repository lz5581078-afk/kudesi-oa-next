酷得斯店铺助手 1.2.0（Windows 10/11 64位）

用途
在授权电脑上运行，接收 OA 的店铺登录、截图和受控远程协助任务。
每家店铺使用独立 Chrome/Edge 登录环境；登录状态仅保存在本机。
助手协助打开平台后台，验证码和最终提现由工作人员在平台内完成。

首次安装
1. 电脑需要安装 Chrome 或 Edge，并能访问 OA、Node.js 官网和 npm 仓库。
2. 在 OA「财务 → 店铺提现 → 授权电脑」生成8位绑定码（10分钟有效、一次性使用）。
3. 完整解压安装包，双击「安装助手.cmd」，填写 OA 地址、绑定码和电脑名称，点击「安装并绑定」。
4. 安装器自动下载并校验独立运行环境，不用手动安装 Node.js。下载及依赖安装进度显示在命令窗口，请勿提前关闭。
5. 回 OA 查看电脑在线后，分配店铺，在店铺列表点击「立即登录」。
不要直接在压缩包内运行；不要绕过公司电脑管理策略，策略拦截时交由电脑管理员安装。

日常使用
- 登录 Windows 后助手自动启动；桌面「酷得斯店铺助手」可打开控制面板。
- 面板显示设备号、OA地址、版本、最近状态和更新时间，提供启动、停止、查看日志和打开OA。
- 关闭面板窗口会收进托盘；托盘菜单「退出面板」只退出界面，助手继续工作。
- 远程协助默认关闭；需要 OA 开启该电脑远程权限，并在本机面板选择「远程每次询问」。每次30秒内确认才允许。
- 远程只操作目标店铺浏览器，受平台域名及会话时限控制；在面板点「关闭远程协助」可取消本机许可。
- 日志：%LOCALAPPDATA%\KudesiAssistant\agent.log；启动日志在 app\launcher.log。
- OA撤销电脑后，助手不再接收任务；重新绑定需要新的绑定码。

升级及卸载
- OA管理员发布.kapkg后可远程升级程序，校验失败不会切换，新版未能及时连上OA会回退。
- 1.2.0新增的桌面入口、控制面板和独立运行环境需要重新运行完整安装包；仅在线升级不会更新这些文件。
- 卸载：PowerShell运行 .\uninstall.ps1。默认保留本机登录环境；加 -RemoveData 同时删除全部本机数据。OA中也请撤销设备。
- 重新安装会重新绑定，安装前关闭正在使用的店铺窗口。

出纳权限
岗位类型明确设置为「出纳」。公司管理员可在岗位档案点击「补齐出纳提现权限」，预览后补充店铺提现入口、店铺登录管理及受控远程协助。
保留原岗位权限和员工个人限制；店铺密码查看、其他财务新增或过账权限不随此操作开放。
