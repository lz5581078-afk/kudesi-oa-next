# 岗位档案部门布局与员工编辑

分支 `feat/position-department-edit`。用户要求岗位档案采用左侧部门列表、右侧展示，并能编辑组织架构里的员工资料。本次未上线。

## 完成内容

- 岗位档案左侧固定部门目录，含全部部门、部门层级、空部门和未分配部门；支持搜索部门、查看岗位数量。选择上级部门包含下级岗位。
- 右侧展示岗位列表，保留岗位搜索、层级、状态、空岗筛选、分组折叠和新增/查看/停用/删除；新增岗位默认带出左侧部门。查看岗位详情时部门导航保留，可直接切换其他部门。
- 组织架构的部门成员表增加“编辑资料”，岗位档案详情的在岗人员也增加同一编辑入口。
- 原员工与权限页的员工表单抽成 `StaffDialog`，三个入口共用。部门/岗位的成员摘要不直接用于保存，编辑前读取完整员工资料及必要选项，保留主岗位、兼任岗位、直属上级、职称、用工类型等原值。保存后刷新相应成员、岗位人数及详情。
- 编辑入口要求 `org.staff.view` 与 `org.staff.edit`，只有岗位编辑权限不会出现员工编辑入口。薪资字段沿用 `org.staff.salary`；无权限时不显示、不提交计薪方式、底薪或时薪。现有后端公司隔离、校验和审计继续生效。
- 员工弹窗通过 portal 挂到 body，避免页面动画影响固定定位；手机采用固定头尾、内容滚动。岗位目录在窄屏上方展示，表格在自身容器内横向滚动。
