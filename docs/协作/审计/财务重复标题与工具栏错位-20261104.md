# 财务重复标题与工具栏错位专项

用户提供组合编码页截图，要求处理重复标题、错位并检查财务其他页面的同类问题。本轮范围是页面标题、辅助维护入口与工具栏，不重做财务业务或逐字段复原。

## 发现与修复

1. 组合编码同名位置重复：顶栏、宿主页签、页内大标题同时出现。财务顶栏提供可访问的一级标题，内容区的重复页面标题统一收起，说明文字保留。手工开单票据、登录管理工作区和弹窗的独立标题保留。
2. 组合编码三个直接子元素被space-between分散：相关按钮集中到一个操作组，宽度不足时按组换行。页面说明与操作的空白缩小。
3. 基础编码、组合编码及库存的辅助资料混在主导航：折叠为“资料维护”，保留所有可访问入口，按原权限过滤；切换后收起、焦点回到菜单，顶栏显示当前子页面名称。返回主页面只移除tab参数，保留其他查询条件。成本表/成本历史等业务切换页签继续保留。
4. 中等宽度的组合列表筛选采用固定输入宽度，导致查询按钮挤窄或卡片内溢出：网格输入允许收缩，按钮文字不折断，手机下搜索占一行，状态与查询另起一行。

仅改web/layout、App的宿主参数及BundlesPage页头，新增局部financeChrome.css和导航/权限回归；没有修改财务计算、编码身份、业务接口、审批或数据库。非财务页面沿用原外壳。
