# UI 重做：财务 · 制单中心（12 种单据页）

范围：导航「财务 → 制单中心」分组下的 12 页：普通销售单、网店销售单、销售退货单、预收款单、收款单、付款单、转款单、预付款单、采购入库单、采购退货单、其他收入单、费用单（以 `packages/shared/src/navigation.ts` 为准；店铺提现在「经营财务」分组，本次不动）。
旧版来源：10-24 源码 `src/finance/FinanceDocumentPages.jsx`、`document-configs.js`（11 种单据共用一个 `FinanceDocumentDraftPage` + 费用单独立页）。逻辑参考：管家婆分销 ERP-A8 说明书（3.3 单据中心、3.4.6 收货管理、3.6.6 出库管理、3.7.2/3.7.3 往来与收付款、3.8.1 现金费用、4.2 单据录入技巧、4.7 多级审核、4.9 快捷键）。
共用组件：12 页全部走 `VoucherPage → DocForm`，差别全部来自 `packages/shared/src/finance-documents.ts` 的单据配置，没有第二套页面。草稿中心里“编辑草稿”弹窗用的是同一个 `DocForm`（弹窗模式），行为不变，只是自动获得新增字段。

## 3. 后端与口径

- 迁移 `1753000000000-DocDiscount`：`finance_documents.discount_cents`（默认 0，只加列；老单据不变）。`amount_cents` 仍是单据金额（优惠后）。
- `DocInput.discountCents`：仅商品类单据；非商品类单据保存草稿时被忽略（存 0），开立校验会报“只有商品类单据能填优惠金额”；优惠必须小于明细合计。
- 费用单 `offset: 'prepayment'`：分录 借费用 / 贷银行(实付) / 贷预付款(冲抵) / 贷应付(余额)；冲抵必须选往来对象（供应商等）；过账沿用原有预付余额检查。
- 新增两个只读接口（均 `@AuthenticatedOnly()`，服务内要求制单/历程/草稿任一权限，全部带 company_id，跨公司对象按“不存在”处理）：
  - `GET /finance/party-balance?partyKind&partyId` → 应收/应付/预收/预付余额、客户赊销额度（需 `resource.finance-customers.view`）。
  - `GET /finance/line-hints?productIds=1,2&warehouseId=` → 账面库存；`lastPurchase*` 仅 `product.cost.view` 返回；`lastSale*` 仅 `product.price.view` 返回（服务端不给字段）。
- 权限键、导航、流程引擎：无改动。店铺提现、经营历程、草稿中心、成本表、基础资料、流程引擎没有改动；草稿中心的“编辑草稿”弹窗共用 DocForm，原有测试全部不改断言通过（仅把“最后一行回车加行”的触发格从单价改为备注，因为回车现在先逐格前进）。

## 4. 没做的 A8 / 旧版功能及原因（需要时再排期；★ 为需要你拍板）

- ★ 收款/付款单“优惠金额影响往来”（A8：优惠金额 + 单据金额 = 扣减的应收/应付）：需要新增“财务费用/现金折扣”科目，会改变损益口径，未擅自做。
- ★ 往来核销单（应收冲应付、预收冲预付、债权债务转移）：改变往来口径，需要单独设计，未做。
- ★ 多账户收付款（A8“多账户选择”，销售一笔钱分几个账户收）：目前每张单据一个收付款账户；转款单已支持多账户。需要时在 `finance_document_accounts` 上扩展。
- 转款手续费（A8 资金调拨单）、付款期限/币种汇率/订单回写/借进转采购/获赠单/换货单/条码/序列号/批次/单据助手 25 项：本系统无对应模块，不做。
- 旧版“单据摘要”文字、旧版 `/api/finance/expense-vouchers` 接口：新系统统一走 `/finance/docs`，备注承载。
- 单据多级审核：由统一流程引擎负责，单据页不写死审批人。
