# 两模块登录远程窗口入口修复（2026-11-03）

范围：feat/session-login-remote，基于 integration 9fb12f1。仅 SessionShops.tsx、对应交互回归和本记录/任务板。原助手 .48 修复仍在独立 session-legacy-reuse 工作树，不混入。

原因：旧 OA SessionManagerPage.openShop 直接 setRemoteShop；新版登录按钮仅 client.open。任务能到达授权电脑，但当前网页没有设置远程弹窗状态。另旧弹窗被不必要的 remoteMap 条目条件遮挡。

修复：旧引擎且具备相应工作区远程权限时直接打开复用弹窗；弹窗先找已存在浏览器，不存在才创建 purpose=remote 打开任务。登录入口不另发普通打开请求。旧弹窗渲染不再依赖远程列表成功；原生仍依赖原状态。无远程权限保留普通登录，不提升权限、不改服务器策略。
