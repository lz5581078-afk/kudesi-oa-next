# 出纳店铺提现权限与助手（2026-11-02）

用户要求：给出纳岗位增加财务导航下店铺提现权限；参考旧助手实现可用程序。本轮未授权上线，未修改生产权限、发布公司助手版本或操作真实提现。

## 权限

出纳工作台增加财务→店铺提现。默认岗位配置增加 `finance.doc-withdrawal.view`、`finance.session.manage`、`finance.session.remote`，以现有共享导航为唯一权限键来源。

已存在的岗位授权需显式应用。公司管理员在岗位档案点击“补齐出纳提现权限”，预览当前公司所有启用、岗位类型明确为 cashier 的岗位；确认后只增加缺失的三项，保留岗位原授权、个人 allow/deny，其他岗位/公司不变。身份以令牌与实际在职公司管理员记录共同校验；预览指纹防止覆盖并发修改，事务内写审计。没有批量开放其他财务开立/过账或店铺密码查看权限。

## 助手 1.2.0

参考旧仓库 `oa/agent/open-shop.js`、`oa/agent/windows/`、`oa/src/session-manager/SessionManagerPage.jsx` 以及本库旧功能研究第04篇；仅参考行为，不复制旧代码。沿用现有设备令牌、平台域名白名单、公司/工作区/店铺隔离的本机 Profile、人工验证码、截图和受控远程协助。

新增双击安装入口、WinForms绑定窗口、独立Node运行环境自动准备、SHA256校验、当前用户数据ACL保护、桌面和启动托盘入口。面板可查看状态/更新时间、启动停止、开OA和日志、设置远程每次询问/关闭。卸载会退出面板并保留或显式删除本机登录环境。

Node运行环境来自官方 https://nodejs.org/dist/v22.23.4/node-v22.23.4-win-x64.zip ，固定SHA256 `cbc74b5e0982c9dbb41525fd8fb5dcd32fbee237863f7829072f4639a1ce5f20`（对照官方 SHASUMS256.txt）。无需全局Node，需要Windows10/11 x64、Chrome/Edge，以及访问OA、Node官网、npm仓库的网络。安装过程无员工账号密码。最终提现由工作人员在平台后台完成。

安装包：`apps/agent/release/kudesi-assistant-windows.zip`；在线升级包：`apps/agent/release/update/kudesi-assistant-1.2.0.kapkg`。首次安装解压后双击“安装助手.cmd”。1.2.0面板/独立运行环境属于安装资产，已有设备需重新运行完整安装包；单独.kapkg在线升级不更新这些文件。

服务端下载器、API资产复制和本地打包共用同组模板。OA内下载安装包仍取当前公司已发布升级包，需上线后发布1.2.0才切换公司可下载版本。本轮不隐式发布或升级电脑。
