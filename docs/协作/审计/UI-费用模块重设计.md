# UI 对照：费用模块重设计（通信费用台账）

分支 feat/fees-redo。入口：资料 → 账号与资质 → 费用模块（`fee-settings`）。没有新迁移。截图在 `截图-费用模块/`（1440 宽用 `-d-`，390 宽用 `-m-`）。

## 1. 设计要点

费用不另存一份。手机费用来自手机号资料（卡类型、主卡、运营商、套餐、月费、充值周期、上次充值、下次充值），宽带费用来自宽带资料（账号、区域、带宽、周期、金额、到期日、绑定手机号）。页面回答三件事：哪些是主卡、子卡挂在谁下面；每张卡多少钱、多久充一次、下次什么时候充；宽带多少钱、绑在哪个号码上。

- 顶部 7 个可点汇总：月均通信费（手机/宽带分列）、主卡数、7 天内要充、已逾期未充、宽带 30 天内到期、未设费用、待整理（孤立子卡、宽带未绑号）。点击即筛选。
- 页签：按主卡 / 全部号码 / 宽带。主卡下展开子卡，只有两级。
- 行内操作：修改、绑定或更换主卡、记录充值、宽带绑定手机号。
- 批量修改：先预览变更再保存，写回手机/宽带记录，留操作日志。
- 规则只在 `packages/shared/src/fees.ts`：月均折算（月付原值、季付除 3、半年除 6、年付除 12、自定义按天数乘 30）、下次充值日、逾期/临近判断，金额全部整数分。
- 后端：`GET /api/resources/fee-ledger`，只读聚合（主卡/全部/宽带视图、聚焦筛选、运营商/使用人/区域筛选、排序、分页、汇总、孤立项），权限同手机号查看，公司只取令牌。
- 规则（`resource-rules.ts` → `fee-rules.ts`）：主卡不能再挂主卡、有子卡的不能设为子卡、不能挂自己；宽带新增必须绑手机号，旧数据不拦截编辑，只在页面标红。

| 旧功能 | 新系统 | 状态 |
|---|---|---|
| 手机号套餐、月费维护 | 费用模块行内修改，字段写回手机号资料 | 有 |
| 子卡挂主卡 | 绑定/更换主卡，两级校验 | 有 |
| 充值周期、下次充值提醒 | 下次充值日自动算，7 天内/逾期汇总可点 | 有 |
| 记录充值 | 行内「记录充值」，更新上次充值和下次充值日，留日志 | 有 |
| 宽带费用、到期 | 宽带页签，30 天内到期/已到期筛选 | 有 |
| 宽带绑定手机号 | 行内绑定；新增宽带必填 | 有，且更严格 |
| 批量改费用 | 批量修改带预览 | 新增 |
| 月费汇总 | 月均折算汇总，手机与宽带分列 | 新增 |
| 旧版 V 系列并存页面 | 只留一个页面 | 合并 |

## 3. 迁移核对（只读演练）

只对 legacy_full 做 dry run，没有 `--apply`，没有写生产库。

- 手机号 319 条新建、1 条复用，宽带 1 条新建，两类均无失败项。
- 适配器补了两处：旧 `recharge_cycle` → `rechargeCycleDays`；宽带位置说明与区域名称唯一精确匹配时写入 `locationId`。
- 旧库当前数据：320 个手机号里 5 个设了月费（月付/年付）、6 个有上次充值、1 个有充值日；没有可迁的子卡关系；宽带仅 1 条，已绑手机号，金额 0，没有区域信息。
- 因此旧库中没有主子卡关系和宽带区域可迁，上线后要在页面里补。测试用的假旧库（`fake-legacy.ts`）覆盖了周期、绑定和区域映射（`legacy-adapter-fees.spec.ts`，3 条）。

## 4. 宽带同步与区域显示

费用模块的宽带页签和资料里的宽带页是同一份数据、同一个保存通道（`/api/resources/broadband`，带版本冲突检查）。费用字段（周期、金额、到期日）就在宽带表单里。

| 项 | 做法 |
|---|---|
| 双向链接 | 费用模块「打开宽带档案」跳到宽带详情（`?open=id`）；宽带详情「在费用模块查看」按账号筛选后跳回 |
| 区域全路径 | 宽带列表、详情、费用模块宽带页签都显示「总部大楼 / 5楼 / 财务室」 |
| 按区域筛选分组 | 宽带列表默认按使用区域分组，组头显示条数和月均合计，未指定的归「未指定区域」；费用模块宽带页签有区域下拉 |
| 房间与档案位置 | 选中区域后显示本区域（含下级）使用的宽带和月均（`AreaBroadband.tsx`，LocationBoard 只加一行，不动 feat/asset-rooms 的布局） |
| 新增宽带 | 表单提示填写使用区域和绑定手机号，手机号必填 |
| 旧数据导入 | 适配器带出区域（见上） |

附带修了一个旧问题：`/resource/<type>?open=<id>` 之前不会打开详情（重置效果把刚打开的记录又关掉），现在只在切换资料类型时重置。
