# UI 页面对照审计：u4「财务资料、成本与聚水潭分类」

范围：`apps/web/src/pages/finance/`（成本表、定价调试、人力成本、快递价格、聚水潭、数据工具、导入）、`apps/web/src/resources/` 里商品与成本相关的通用页面（商品档案及七个页签、包装方案、供应商/客户/费用档案及分类、基础编码、组合编码等）、`apps/web/src/pages/flow/SkuApply.tsx`（SKU 批量申请）。

旧系统：`src/finance/*.jsx`、`src/workflow/BundleApplicationCenter.jsx`、`src/finance/product-archives/*`（只读参考，没有复制任何代码或样式）。

本轮只看**页面层**（功能区划分、按钮入口、列与筛选、复制/提示/确认/空态、移动端）。字段与后台规则上一轮已在 D/E/F 审计里对过，不重复。

## 总体结构差异（影响所有页）

| 编号 | 旧系统 | 新系统 | 状态 |
|---|---|---|---|
