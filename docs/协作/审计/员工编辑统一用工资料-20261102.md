# 员工编辑统一用工资料

用户要求取消“为已有账号建档”，已有人员直接在员工编辑里修改用工类型与合作期限。新员工仍可通过对应类型的入职码加入；原“新增账号并建档”人工入口保留。

桌面/手机/空列表不再显示已有账号新增建档；详情不提供复制用工档案，网格不再追加已有账号新行。未建档提醒统一打开完整员工编辑，人员档案/部门/岗位入口共用同一编辑器，读取当前合作期限后再编辑，避免把旧期限覆盖成今天。

员工编辑新增合作开始、结束日期，沿用共享校验：临时工结束日期必填、兼职可以清空、日期必须真实且结束不早于开始。服务端在员工更新同一事务中按公司与账号ID找到唯一用工档案，调用通用资料引擎补建或更新；不按姓名匹配、不创建第二个账号、不重置密码或飞书绑定。档案创建需要resource.workforce.create，更新或转正式需要resource.workforce.edit，保留org.staff.edit和薪资独立授权。仅明确提交用工类型/日期时联动，普通岗位、薪资等接口操作不隐式补档。

转为正式员工时在原事务软归档用工记录，保留合同、计薪、联系人及资料变更历史，不执行账号停用或交接。历史资料可通过兼职页筛选“已归档”查看；没有通用直接恢复按钮，再改兼职/临时工从员工编辑恢复原记录，并重新校验合作期限。自动恢复仅接受本功能转正式产生的归档，其他来源归档不擅自恢复。账号状态、计薪、权限及业务历史保持原有规则。

员工编辑锁定账号，重复/并发保存复用原记录；用工档案写入增加账号与当前档案锁和旧快照校验，转正式后打开着的旧档案不能覆盖回兼职。账号、档案、日志整笔事务，任一步失败回滚。
