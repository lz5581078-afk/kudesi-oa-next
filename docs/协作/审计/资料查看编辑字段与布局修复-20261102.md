# 资料查看编辑字段与布局修复

## 触发问题及结果

用户反馈最近资料UI调整后，查看遗漏编辑字段（例如直播权限），切换模式时字段错位。正式只读复现：历史自媒体账号直播权限为未存储值，列表/详情显示空白或“—”，编辑器却为未勾选。

- 通用查看与编辑共用字段顺序、权限、显示条件、整行规则；详情内整条编辑沿用当前抽屉，运营部门等只读字段保留原位置，但不提交。新增/列表编辑沿用公共字段布局。
- 未存储开关明确显示“否”，提交未填写开关时使用false；多选值显示中文，缺少引用名称保留编号，JSON按结构显示。
- 隐藏空字段偏好按资料类型分别保存，不再将其他资料的偏好带入本页。空开关也不会因隐藏空字段而消失。
- 商品查看从同一product-layout读取分区、顺序、显示条件和字段；补回赠品简称、形态、零值原因、OEM相关重量等，保留来源、组成、历史成本的只读业务展示。
- 供应商、客户、费用类型空的补充字段仍有查看位置；费用归属对象要求在查看显示。基础编码/组合编码补齐专属资料与其余配置字段，继续执行成本/售价权限校验。
- 详情内编辑固定保存栏；手机导航横向滚动；关闭详情时编辑器先检查未保存修改，编辑期间避免切换记录、页签或执行其他详情动作。
