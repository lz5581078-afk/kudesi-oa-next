# 直播排班：账号与本场店铺选择

## 页面规则

- 直播账号表示本场使用的自媒体账号；本场店铺表示该账号此次直播参与业绩统计的店铺。两者可以同名，但不是同一项资料。
- 新选账号只有一个同平台关联店铺时，一次勾选即同时带入账号和店铺，卡片显示店铺名称及「已自动选中，无需再次勾选」，不再显示第二个店铺复选框。
- 新选账号关联多个同平台店铺时，不擅自全选。卡片内展开「选择本场店铺（可多选）」，至少选择一家；保存缺项时点名对应账号。
- 无关联店铺时提示先维护自媒体账号档案；没有自动创建或修改档案关系。历史记录缺失的单店选择可通过「使用此店铺」明确补齐，历史账号不可用时可移除重选。
- 切换平台保留其他平台的已选账号，并继续显示已选卡片。取消账号同步移除该账号本场店铺选择。
- 编辑或导入已选店铺仍保留原选择，不因账号另有关联店铺就追加未参与店铺。原有后端校验继续生效。
- 同一店铺业绩合并填报；本场计时工资只计算一次，提成按平台分别计算。

## 排班布局

排班弹窗按「时间与直播间 / 本场人员 / 直播账号与本场店铺 / 产品与备注」四组排列，时间标明北京时间、跨日与冲突规则，保留导入上次排场及试播主播入口。账号改为两列卡片，手机改为单列，选择统计显示账号数与去重店铺数。底部保存/取消固定，内容区独立滚动。

排班列表显示全部账号及对应店铺，避免多账号排场仅露出首个账号。

共用账号选择器同步用于报上播，不改变请求结构、后端、权限、数据库或实际业务记录。

- 本地合成数据预览验证 1440×1000 桌面与 390×844 手机：单店只出现账号勾选，多店展开选择，选择后统计由 2 账号/1 店更新为 2 账号/2 店，底部操作可见。
