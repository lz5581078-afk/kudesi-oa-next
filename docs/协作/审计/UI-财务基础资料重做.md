# 财务 · 基础资料四档案：按旧版分级布局重做

范围：商品档案、供应商档案、客户档案、费用档案。旧版对照源码为 10-24 版（只参考布局和操作，不复用代码）。
截图：`docs/协作/审计/截图-财务基础资料/`（before-* 为改前，after-* 为改后；d=1440 宽，m=390 宽）。

## 一、旧版怎么长的
- 第一级：顶级分类卡片（带数量），页头有“管理顶级分类”，卡片上有编辑、删除、排序。
- 第二级：“返回上一级” + 标题 + 副标题；左边分类目录，右边列表。工具栏有导入导出、批量、显示停用、新增（只能在最末级分类下新增）。每行操作：查看 / 编辑 / 复制新增 /（成本明细）/ 停用或启用 / 删除。

## 二、新系统怎么做的（配置驱动，四档共用）
- `ResourceDef.hierarchy`（`packages/shared/src/resources.ts`）：`kind` 为 `tab`（商品：顶级是档案类型）或 `category`（供应商/客户/费用：顶级是一级分类）。四档只在 `finance-resources.ts` 里各配一段，页面代码只有一套：`ArchiveHome`（卡片）、`HierarchyPage`（用地址 `?g=` 记住当前在哪一级，可刷新、可分享、浏览器返回有效）、`HierBar`、`HierRowActions`。
- 列表仍是原来的 `ResourcePage`，权限键 `resource.<key>.*`、服务端成本/价格脱敏、商品编码、档案类型、单位全部沿用，没有动。

## 三、功能对照

| 旧版功能 | 新系统 | 状态 |
|---|---|---|
| 顶级分类卡片 + 数量 | `ArchiveHome` 卡片，数量由列表接口汇总 | 新做 |
| 管理顶级分类（增/改名/排序/删除） | 卡片页“管理顶级分类”，复用目录的管理模式；删除要写原因 | 新做 |
| 返回上一级 + 标题/副标题 | `HierBar`；地址 `?g=` 记录层级 | 新做 |
| 左侧分类目录（多级） | `CategoryTree` 加 `rootId`，只显示该顶级下的树，带“全部xx” | 已有，改造 |
| 只能在最末级分类下新增 | 供应商/客户/费用：没选到最末级点新增只给提示；商品沿用表单内的末级校验 | 新做 |
| 导入 / 导出 | 沿用已有导入对话框和导出 | 已有 |
| 批量操作 | 沿用 `BatchBar`，新增“批量删除”（逐条、同一原因） | 已有 + 新做 |

| 行：查看 / 编辑 | 行内按钮（编辑直接打开表单；查看打开详情） | 新做 |

| 行：成本明细（商品） | 行内按钮直达详情的“成本”页签；没有成本查看权限的人看不到按钮，服务端本来也不返回 | 新做 |

| 手机端 | 卡片单列；目录折叠成“分类目录”；操作收进详情 | 新做 |

## 四、有意优化（不是照抄）
1. 层级写进地址，刷新/分享/后退都不丢位置（旧版刷新会回到第一级）。
2. 新增被拦时说明原因（“请选择最末级分类后新增供应商”），而不是按钮灰掉没解释。
3. 停用、删除、批量删除一律要写原因并进审计，旧版直接弹确认。
4. 行操作按权限显示；没有成本权限的人不出现“成本明细”，且接口本身不返回成本。
5. 四档共用一套页面和样式，以后新增资料只配 `hierarchy`。
6. 分类码不用手填，减少新增分类的步骤。

## 五、没做的旧功能与原因
| 旧功能 | 原因 |
|---|---|
| 手机端卡片内联行操作 | 屏幕窄，编辑/复制/删除统一从详情进入 |
| 分类标识（编码）在目录里直接改 | 编码影响已生成的编号，仍只在“资料维护”里改 |
| 分类“移到别的上级”、费用项个人拖拽排序偏好 | 分类移动规则已在服务端（只能在同一顶级树内移），页面入口暂不放；个人排序偏好用得少，暂不做 |
| 供应商/客户长格式自动编号（GYS-主类-类-首字母）、银行信息“一键复制全部” | 新系统沿用既有编号规则，未改动；银行信息逐项可复制 |
| 费用档案“存为历史包” | 已由“费用存档表”覆盖 |
| 旧版 CSV 导入导出格式 | 已由统一导入导出覆盖 |

## 七、上线后管理员要做
- 新公司如果分类/费用档案为空，先在对应页点“导入默认分类/默认费用档案”，卡片页才有内容。
- 顶级分类现在可在卡片页“管理顶级分类”里增删改排序；原来在“资料维护”里的分类仍然可用。
- 无迁移、无需重新授权；权限键未变。
