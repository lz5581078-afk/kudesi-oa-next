# 财务基础资料设计对照（2026-11-03）

分支：`feat/finance-base-design-parity`，基于 `origin/integration` 的 `615c322`。用户要求基础资料及点开的相关页面按24号源码呈现，保留已有字段和功能。

## 已实现

- 四档首页恢复标题、说明和名称/数量/说明分行的卡片；商品与往来档案分别使用参考的卡片颜色、标识、说明及间距。商品分类数量取现有只读目录接口；读取失败不编造数量。
- 往来档案恢复分类引导、独立目录与列表面板；商品工作区恢复返回栏、目录与列表的比例、边框和控件密度。
- 分级列表改为“资料操作”工具栏。搜索、筛选、行高、表格编辑、导入、导出仍可从菜单进入；显示停用、显示列、新增和行内查看/编辑/复制新增/成本明细/启停/删除保持现有权限和调用链。
- 顶级分类改为独立编辑窗口，恢复已有分类标识字段，原有分类说明仍可展开修改。原有箭头排序保留，拖拽共用已有事务排序接口。
- 财务专用表单从通用 `resource-editor` 样式中隔离，恢复各档案已有参考窗口的尺寸、滚动区、12列字段配置和底部按钮排列；修复通用字段容器引起的标题竖排/居中问题。
- 供应商分类选项改为参考的复选卡片；当前结果以外的历史选中项仍在复选列表中，可保留或取消。字段和值未删除。
- 包装方案、零值原因、单位与规格、供应商/客户/费用分类等现有相关资料页接入同一财务外观。分类管理、字典管理、历史包、导入及子资料仍复用现有组件。
- 查看窗口恢复原有财务分类型背景；移动端保持内容滚动和固定底部操作，修复分类目录折叠后留白。

## 范围边界

没有数据库迁移，没有修改接口、金额/成本规则或权限定义，没有删除已有资料字段或业务功能。新增读取和排序均复用既有资源接口。未合并 main、未部署、未连接生产数据库。

新增系统原有的功能入口（查看全部、表格编辑等）依照“保留已有”要求仍可进入，因此不承诺它们与旧源码完全相同。现有列表字段与用户列设置保留，未为了截图隐藏业务字段。
