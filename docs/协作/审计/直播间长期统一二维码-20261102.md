# 直播间长期统一二维码

入口：直播管理全览中的直播间房间设置，生成/查看/打印/重新生成。一个直播间仅一个码，上播下播共用；打开和保存房间资料均不自动换码，无时间过期。换码需确认，成功提交后旧码立即失效。读取失败可重试，换码响应不明时回读服务器当前码，避免错误展示旧码。

服务端32字节随机令牌，CryptoService加密持久保存、SHA256摘要校验，不含登录凭证。查看和换码沿用live.manage；扫码要求本人登录及既有业务权限，companyId仅来自登录身份。校验启用直播间及本公司，拒绝伪造/跨房间/跨公司/旧固定链接；同时换码用公司锁和版本冲突保护，只生效一次。审计仅记版本，不记录令牌。扫码状态读取及上下播确认再次校验令牌，已打开旧页面也无法继续提交。登录/飞书绑定回跳保留令牌，30分钟仅为登录意图暂存期限，二维码本身无有效期限制。普通本人工作台不依赖二维码。
