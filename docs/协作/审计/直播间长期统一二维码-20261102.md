# 公司通用上下播二维码

直播管理最后一个标签“上下播二维码”（在“通知设置”之后），直接进入独立页面，可查看、打印、生成或重新生成。顶部按钮和弹窗入口已移除，沿用live.manage及分区记忆/链接定位。全公司所有直播间、上播和下播共用一个长期码，不绑定直播间，平时查看不自动换码。扫码登录后，未上播者先选直播间；按该房间筛选本人排班/可加入场次，临时上播也固定为所选房间。运营身份选择仅列该房间候选。已经实际打卡者直接显示本人场次的下播按钮，无需再选房间。原房间设置中不再提供二维码。

服务端32字节随机令牌，CryptoService加密持久保存、SHA256摘要校验，无过期时间。查看和换码沿用live.manage，扫码及业务提交继续要求本人登录和原直播权限。companyId只取登录令牌；拒绝伪造及跨公司使用。公司锁和版本条件防止同时换码覆盖，审计只记版本。换码成功后旧码立即失效，旧扫码页的状态读取和上下播确认都再次检查令牌。二维码只作为入口，不含登录凭证。登录/飞书绑定回跳保留通用公司链接及令牌，30分钟仅为临时登录意图保存期限，不影响二维码有效期。普通本人工作台不依赖二维码。
