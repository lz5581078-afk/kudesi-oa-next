# UI 页面对照：财务单据与实时查询（u3）

旧代码：`src/finance/`（FinanceDesk、FinanceOverviewPages、FinanceDocumentPages、document-configs、finance-ux）、`src/session-manager/SessionManagerPage.jsx`。
新代码：`apps/web/src/pages/finance/`。状态：✓已有 / ✗缺失 / ≠不同（有意不同或等价实现）。测试名均在 `fin-ux.test.tsx`（简称 UX）或 `finance-queries.test.tsx`（简称 FQ）、`sale-return.test.tsx`（SR）。

## 1. 财务经营  FinanceDesk → FinanceOverviewPage
①布局：旧=统计期间条（日期快捷+起止日期+刷新）→汇总卡（收入/成本/利润/账户余额，可点）→利润趋势+店铺利润并排→最近台账。新=期间条（月份+全部时间）→经营指标→往来资金→趋势→店铺利润→台账→待处理，纵向。
②细节：
- 期间快捷（本月/上月）✓补（UX 财务经营）；任意起止日期 ≠（接口按月/全部取数，不改后端）
- 刷新数据按钮 ✓补
- 汇总卡点击→经营历程并带期间/方向 ✓补（UX 点销售收入）
- 账户余额卡点击→现金银行 ✓补
- 利润率/毛利率提示 ✓补；店铺利润率列 ✓补（UX 店铺利润有利润率列）
- 无数据空状态+去经营历程 ✓补
- 台账“全部单据·经营历程”按钮 ✓补；台账单号点开详情 ✓已有（新比旧强）
- 往来余额、待处理草稿 ✓已有（新增内容）
③优化：记住期间（旧存本地）≠（新用月份状态，不记）。
