# 补报账号店铺差异确认

用户要求：原排场账号与店铺当前关联不一致时，提示后可按本次补报的数据提交。

补报专用校验在账号与店铺同公司、同平台且均有效的前提下，收集未关联差异，首次返回LIVE_MANUAL_CHANNEL_CONFIRM_REQUIRED，不写场次；页面展示账号/店铺差异、实际时间和金额，返回核对保留填报内容，确认后仅重发该份数据并带confirmUnlinkedStores。服务器事务内再次校验，将差异及确认标记写入现有业务审计，不修改自媒体账号档案，不替代审核。

其他开播/排场接口不传补报回调，仍强制关联。跨公司、跨平台、停用资源、重复店铺编号、时间冲突、结算锁定及原排场引用仍拒绝，无数据库迁移、不改人事授权、不写生产测试数据。已有实际场次沿用原快照的逻辑保持。

因integration缺少当前线上排班补录实现，本轮在最新main正式组合验证；后续开发集成仅提交本功能范围，正式分支保留可直接审阅的原排场回归。
