# 岗位首页与功能权限调整

用户口径：默认进入本人岗位工作台，兼岗可切换；岗位开放功能入口，具体新增、修改、审核、过账等由流程节点和办理人决定。此前人事部203项授权保持不变。

## 实现

- 登录成功及根路由默认到岗位工作台；按服务端主岗位、兼岗目录选择本人岗位。未分配岗位不自动进入其他人的工作台。岗位首页对已登录用户可用，业务页面及数据仍单独鉴权。
- 从现有岗位类型、层级、工作台常用入口和汇总模块生成页面权限，不根据已过滤的菜单反推，不根据岗位名称猜工作台。
- 不批量授予资料增改删、财务开立/过账、直播管理等全局操作键。流程专用的采购入库草稿能力保留实际入库节点、办理人、公司和状态校验，不能凭岗位权限绕过流程。
- 公司管理员在岗位档案中预览并应用当前公司的配置。普通有岗启用员工清除个人额外允许/拒绝，主岗和兼岗权限继续由现有认证逻辑合并。管理员身份、停用员工、无有效岗位员工个人授权保留。
- 按真实部门父子关系保留人事部及下级部门的岗位与人员权限。人事人员兼任岗位也保留，避免间接改变现有授权。
- 预览指纹覆盖岗位、部门、人员归属、岗位授权、个人覆盖和目标配置；变化则拒绝旧计划。应用使用事务并记录完整前后计划，审计失败也整批回滚。
