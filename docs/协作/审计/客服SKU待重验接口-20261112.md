# 客服SKU待重验接口

客服同步原先只读取已验证组合。基础编码变更使组合进入 reverify 后，组合从接口结果消失，接入方随后将其当作缺失停用。

旧接口 `/api/external/verified-bundles` 的分页、`/all` 和 `/:code` 新增可选查询参数 `includeReverify=true`。保留 `verified_bundle_read` 密钥用途、公司隔离和原响应形状。默认仍只返回 verified；显式开启时返回 verified 与 reverify，验证状态按实际值返回，不更改任何验证结果，不因成本待完善过滤客服身份资料。pending、停用及归档不纳入此范围。其他成本目录接口的规则不变。

客服端每页显式携带该参数，完整分页校验后按现有版本流更新发生变化的商品、分类和SKU。接口失败、分页异常、空响应或减少均不得把未返回的本地记录停用或删除；继续使用已保存版本。人工维护和人工绑定保护不变。

本变更不含迁移，不直接修改生产商品、验证状态或聚水潭数据。发布应先更新OA接口，再更新客服端；通过正常自动同步恢复此前因 reverify 被停用的自动记录。
