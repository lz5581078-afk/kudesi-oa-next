# 任务板

多个窗口（Claude、Codex 等）并行开发时，只通过 Git 分支和这个文件协作。开工前先读，认领后再动手，收工后更新。

## 任务

| 任务 | 状态 | 分支 | 说明 / 范围（会改的目录和共用文件） |
|---|---|---|---|
| （示例）XX 页面改版 | 进行中 | feat/xx | 只改 apps/web/src/pages/xx；共用文件：无 |

状态只用：待认领 / 进行中 / 待合并（PR 已提）/ 已合并 / 暂停。

## 迁移占用

迁移文件编号按时间戳递增，两个窗口同时新建会撞号。新建前先运行 `bash scripts/collab/next-migration.sh`，再把用的编号登记到这里。

| 编号 | 用途 | 窗口/任务 |
|---|---|---|
| 1730007000000 | AgentReleases（助手更新包） | 已合并基线 |

## 共用热点文件（只做最小追加式改动，不整体改写/格式化）

- packages/shared/src/navigation.ts（菜单、权限、页面标签）
- packages/shared/src/resources.ts、finance-resources.ts（资料定义）
- apps/api/src/resources/finance-rules.ts（财务规则）
- apps/api/src/database/data-source.ts、entities/index.ts、app.module.ts
- apps/web/src/App.tsx、styles.css
- package.json / package-lock.json（加依赖要在任务说明里写明）
