# 全览人员上播状态和实际账号

用户要求在直播全览姓名后小字标记是否报上播，明确缩短为「已报 / 未报」；卡片右上方显示实际直播号名字。

## 实现

- 本场主播、中控、运营分别按company/session/user/role匹配live_session_checkins，只要本人有本场上播记录即为已报，即便已下播也保留事实。当前打卡模式下无记录才是未报，不能把整场已开播当所有人已报。
- 历史非个人打卡场次仅能从started_by/started_role确定最初上播人，其他人显示未记录，避免伪造未报。无人员不显示状态。
- 全览接口在原场次查询之后批量获取个人打卡，严格按公司和返回场次限定；保持现有访问权限。
- 卡片房间标题下右侧显示本场channels_json实际账号名称，保留多账号完整快照；历史无channels数据回退本场douyinAccount快照，不读取下一场计划号。回看已结束场次标为上场直播号。
- 原南北房间、大房双宽、人员三列、营业额、进度、下一场与详情结构保留；状态9px，姓名与状态同一行，长姓名保留title全文，账号可换行。既有全览自动刷新同步更新信息。
