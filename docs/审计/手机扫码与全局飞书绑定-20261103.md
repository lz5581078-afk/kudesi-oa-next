# 手机扫码与全局飞书绑定

用户明确要求修改后上线：重新设计扫码上下播手机界面，分开绑定/稍后按钮，未绑定账号在所有业务页持续提醒，修改密码页提供绑定入口。

扫码页面采用本人身份、当前状态、步骤、直播间与操作卡的单列布局；上播/下播继续调用原业务处理。手机确认弹窗整屏布局，内容独立滚动，底部操作固定在弹窗内，表单单列，时间和金额不挤列。二维码校验、人员角色、上下播确认、计时、工资提成及报告处理未更改，无后端或迁移。

Shell 内统一显示不可关闭的绑定提醒，绑定完成随用户状态刷新消失。独立引导页仍可稍后绑定，但返回后各业务页继续显示提醒。绑定/稍后按钮各高50px、纵向间隔24px，原扫码入口在前往绑定及稍后返回时保留，沿用原有同源路径校验。

修改密码页保留独立飞书绑定卡，显示未绑定/已绑定/状态待确认。状态接口异常不隐藏入口，仍可调用原授权启动接口重试；绑定按钮不提交密码表单。未执行真实密码修改、飞书绑定或上下播，也不发送测试通知。
