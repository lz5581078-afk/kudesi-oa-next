# 全览时间轴起止时间标注

用户要求在每个直播间卡片下方时间条的开播、下播位置上方，用很小的字标注时间。

- 原时间条抽取为单一RoomTimeline组件，保持06:00至次日02:00范围、色条状态、位置比例和当前时间指针。
- 起止端点上方使用9px等宽小字及短刻度；共用端点仅显示一次，跨日带日期。标签根据实际卡片宽度避开重叠和边界，无场次不补造时间。
- 直播中的排场结束位置提示预计下播；临时直播延伸至当前时间处提示直播进度，未开始/过时排场提示计划下播，避免误标实际结束。
- 不改后端时间源、排场、直播或营业额，仅前端展示，无数据库迁移和生产数据写入。

验证：根目录typecheck和npm test通过；时间轴及全览21项专项通过，覆盖密集短场次、相接端点去重、跨日、预计下播/进度和空场次。1920px与390px真实DOM检查无标签交叠、越界或整页横向溢出。用合成数据渲染真实OverviewTab，截图/tmp/timeline-times-preview.png，重点卡片/tmp/timeline-times-card-preview.png。
