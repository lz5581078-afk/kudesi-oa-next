# 定价调试公司低价独立权限

用户要求传统运营部门岗位可以查看定价调试表中的公司低价，并明确成本明细仍需隐藏。新增特殊权限 finance.pricing-debug.floor.view，岗位目录显示“定价调试表：查看公司低价（不含成本明细）”，页面入口权限 finance.pricing-debug.view 仍单独校验。不会默认给全部运营或任何公司岗位自动授权，也不新增或变更人员权限。

定价调试商品列表、试算结果和 Excel 导出按公司低价权限返回 minPriceCents；发货前成本仍只允许 product.cost.view。保留原成本查看人员的既有低价查看能力及内部数据标记；新权限不改变整元试算规则、商品成本表、成本明细或成本维护接口。前端增加独立可见标记，列表和已选结果表都按该标记显示公司低价，不将低价权限当成成本权限。修复原无查看权限的导出仍携带公司低价列的问题，导出列同样由服务端控制。

实际传统运营部门岗位授权尚未执行：当前 OA 管理员登录失效，需功能发布及管理员恢复登录后读取真实部门与岗位，逐项仅追加新权限，保留原权限；涉及敏感价格数据访问的实际保存需按工具要求在操作前确认具体范围。不通过代码启动、迁移或后台默认授权修改生产权限。无结构迁移，无业务价格写入。

验证：类型检查、全工作区常规测试和构建通过；独立 MySQL 成本/定价及岗位权限 2 套/28 项通过，覆盖只授低价不泄漏成本、试算结果不变、导出列隔离、撤销权限立即脱敏和原成本用户兼容；前端补充低价独立展示及未授权隐藏测试，权限目录补充可授权和唯一键测试。
