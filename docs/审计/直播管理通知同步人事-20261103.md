# 直播管理通知同步人事

用户追加要求：直播管理里所有发给总经理的通知，同步发给人事部门。沿用本轮“修改后上线”授权，验证后单独发布。

识别本公司在用的人事、总经理/总经办部门及其有效子部门，包含本人部门、主岗和兼岗，排除停用人员、停用部门和其他公司。复用原有开播通知接收人规则，并补人事/人事部门别名。

在统一通知落库入口执行抄送，范围仅直播事件、排班及 live-session-review/live-settlement 两类直播流程；其他业务流程、普通公司通知不扩散。总经理原通知成功落库时，向人事生成同标题、正文、链接的信息副本。抄送不是新增审批人或待办，不修改业务页面权限、工资或审批规则。经营/系统类原收件人仍先通过原权限检查，人事获得本通知副本而非页面授权。

事件登记与通知/出站在同一事务内，复用直播通知去重表；人事同时是直接收件人、兼岗或存在多个总经办收件人时避免重复。流程催办按一次通知批次生成键，避免同批次直接收件人和副本重复。仅处理新发生的原通知，不扫描旧通知补发，无数据库迁移。

飞书沿用原通知通道、总开关及本人绑定/个人通知开关。副本记录原通知编号，出站前复核同公司当前人事成员及当前总经理来源；直播事件还按原收件人的配置、权限和当前事件有效性复核，因此移除接收人、告警恢复等情况不会发送过期副本。排班副本保留原资源编号，继续由原取消逻辑作废。未绑定仍有站内通知。
