# 自定义单人飞书通知与发布

用户本轮要求消息内容可自定义，修改好后上线。本次在PR #203的人员绑定状态/单人通知上修改，保留正式、兼职、临时人员的状态展示和通知权限、开关及队列控制。

入口改为「发送飞书通知」。标题最多100字、正文最多2000字，默认保留测试示例，可自行编辑；先预览接收人、标题和换行正文，可返回修改，确认后才入队。消息结果仍区分待发、发送中、成功、失败和暂停，成功表示飞书接口确认。

服务端拒绝空白、超长及无效控制字符；正文规范换行，OA通知与飞书队列保存同一份内容。重复请求编号必须对应相同接收人和内容，改内容时返回409，不覆盖原消息。提交结果未知时前端锁定已提交内容，使用同一编号重试；明确的提交拒绝允许修改后重试。审计只记录长度和通知/任务编号，不再复制消息正文。

本轮明确授权上线，发布以最新main为基础，仅带入尚未上线的PR #203功能和此次自定义内容修改；不整批发布integration其他差异。无数据库迁移，不增加解绑或群发，不自动打开通知开关。

验证：开发分支常规全工作区测试通过，独立MySQL的通知/切库/接入/HTTP专项25项通过，覆盖自定义内容一致性、同编号内容冲突、越界输入、权限和身份边界；合成浏览器中自定义标题和两行正文的预览/确认/模拟结果通过。正式组合将重新运行类型、全量测试、构建和发布控制器测试后发布。

发布组合首轮全量回归中的旧远程协助“模拟一小时”测试超过默认5秒，引发后续模拟时钟串扰；本次只给该长用例设置30秒，保留全部循环、时限及其他断言，不改远程协助业务逻辑。
