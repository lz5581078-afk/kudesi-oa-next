# 工资提成明细场次时间产品

用户要求在运营提成的场次明细中直接看到几点到几点、什么产品。

- 日期列改为日期、实际直播起止、直播间/平台、场次产品四行。主播工资、中控工资共用页面同步受益。
- 使用已保存的 live_sessions 起止及 live_session_products 名称/规格快照，保留手填产品。跨日下播显示日期；结束或产品缺失明确提示。计薪时长仍独立显示，不用零工资推算直播时长。
- 提成接口在原可见公司/人员范围内批量读取产品，只返回基础显示字段；无成本查询、无权限变更、无迁移。所有金额、提成及计薪公式保持原逻辑。
- CSV 在现有列后追加直播开始时间、直播结束时间、场次产品。

验证：npm run typecheck、npm test（shared 354、API 常规 331、web 1077、agent 75）、隔离 MySQL 直播 23 项及 web 构建通过。API 回归覆盖结束时间、手填产品与跨公司产品隔离；前端覆盖同日同房间不同场次、仅提成零工资、跨日与缺失字段及导出。
