# 商品及 SKU 编码身份固定（2026-11-04）

用户更正：商品变更后商品编码不能变，组合编码已包含它，聚水潭也已上传。此规则优先于 24 号源码中自动重编的旧行为。

## 修复

- 商品及基础编码保存后沿用原编号；禁止清空、人工改号、导入更新或内部资料联动改号。
- 已验证、待重新验证、已上传、已生成发布或外部导入的组合沿用原商品及款式编码。持久锁定标记由服务器管理，退回待验证也不解锁。
- 新建商品、复制新增及尚未发布的组合草稿继续按原规则生成首次编码。
- 商品名称、规格、分类、重量、成本继续更新到基础资料、组合、成本表及调试表；资料变更仍触发重新验证，历史快照保留。
- 修正包装编辑将空 code 传给服务器请求重新生成的入口。编辑页锁定编码，保留已有功能入口；批量按命名规则更新时，已发布身份不变。
