# 用工列表账号与试播资料

第一列原为人员引用，显示的是人员姓名，不是 OA 登录名。现统一标为“姓名”，另列真实 OA 登录账号、登录密码、资料状态。

用户已确认：明文显示今后在此设置的新密码。历史 bcrypt 密码不能还原。新建/设置账号时，在同一事务中保存 AES-256-GCM 密文与当前密码哈希快照；本人或其他入口改密后，快照不匹配，列表停止返回旧密码。未设置登录密码的试播账号显示“未设置”。

密码读取使用独立 POST 接口、禁止缓存，须用工查看权限；明文额外要求现有“重置员工密码”权限。跨公司、正式人员、公司管理员不返回凭据。查看审计只记录用户编号，不含密码、密文或哈希。凭据不写进通用 ResourceRecord，通用导出和网格保存不带密码。

未建档的在用兼职/临时工（包括 live_trial 试播人员）以黄色行显示在“全部”第一页，另计待补资料人数，支持姓名/账号搜索；合同相关筛选不把未知合作期当成已合作。点姓名/补资料进入原建档表单；设置账号密码直接使用原人员 ID，不隐式建档，不改变直播试播标志、用工类型、停用状态或直播历史。未建档行不参加批量操作和网格编辑。手机卡片提供相同操作。

新增结构迁移 1774000000000：workforce_login_secrets，注册于 data-source 并加入切换结构清单。无历史密码回填，无生产数据写入。

验证：类型检查、全量常规测试、生产构建；隔离 MySQL 全量 183 套/1143 项通过，最终凭据边界专项 8 项通过。前端覆盖姓名/账号分列、密码权限、试播黄色行、批量选择隔离、补资料入口、未建档账号路径与搜索。使用本地虚构数据完成桌面、390px 手机卡片及空白设置弹窗检查；未操作任何真实账号。
