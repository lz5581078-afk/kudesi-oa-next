# 中控下播与直播间状态同步（2026-11-03）

## 问题与业务规则

线上只读查看南7的09:56场次，唐亮的中控下播报告已保存（12:18），场次仍为直播中，主播没有下播报告。用户补充主播没有登记上播，要求此时中控下播后直播间立即结束。

原代码只在主播下播或试播代报时结束整场；普通场次即使主播没有实际打卡，也会等主播报告或30分钟锁场。个人工作台又直接显示整场状态，扫码面板成功提交后没有即时刷新父工作台。

## 修改

- 根据当前公司、场次、岗位及本人实际打卡判断结束：实际主播存在时由主播下播结束；没有主播实际打卡时，由实际中控下播结束。
- 同一事务保存下播记录、结束整场并结束对应排班，房间占用立即释放。
- 每分钟扫描器根据已保存的打卡下播时间，同步旧代码遗留的直播中状态；锁定公司和场次后重新判断，实际主播未下播时不提前结束。
- 保留原有首报后30分钟填报、订单归集及审核规则，不补造主播打卡、报告或工资。
- 工作台显示本人上/下播状态与时间，未上播本人不显示下播入口；实际下播与整场仍直播的情况分别展示。
- 下播成功即时刷新工作台；扫码或其他标签操作后回到页面也刷新，忽略晚到的旧请求。排班状态只按准确场次关联展示，将来排班保持未开始。
