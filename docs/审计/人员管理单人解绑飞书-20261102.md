# 人员管理单人解绑飞书

用户要求后台人员管理支持给单个员工解除飞书绑定。原页面只有取消全员关联，现保留原入口并增加员工行内「解绑飞书」。

## 行为

- 仅公司管理员可见单人解绑入口；后端同时校验人员查看/编辑权限和数据库内有效公司管理员身份。
- 先读取该员工姓名、OA账号、关联数量，明确保留员工档案、岗位、工资和业务记录；点击「确认解绑此员工」才执行。未绑定时说明无需解绑。
- 清除该员工当前及旧应用的全部飞书身份，同时清除其旧授权状态。按登录令牌公司和目标员工限定，不影响其他员工和公司。
- 事务使用与绑定完成相同的公司锁；预览指纹发生变化返回409，避免旧确认误删新绑定。写入staff.feishu.unbind审计，不记录飞书标识和密钥。
- 成功后可刷新人员状态；解绑本人时同步刷新认证状态。员工可用OA账号密码登录重新授权本人企业飞书，恢复通知。继续保留现有「提醒绑定、不拦截」策略。
- 失败后必须重新读取绑定状态，再决定是否确认，避免盲目重复操作。
