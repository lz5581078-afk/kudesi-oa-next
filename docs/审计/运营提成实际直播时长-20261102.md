# 运营提成实际直播时长

用户反馈运营页时长应保留，仅没有时薪和时间工资。原因是页面原来把工资记录的计薪分钟用作直播时长，纯提成人员没有工资记录因而为零。

- 提成查询额外返回 liveMinutes，由服务端根据场次实际秒级起止计算、四舍五入到分钟；缺失/非正序时间返回null。原公司/本人权限与金额均保持。
- 运营页详情显示直播时长，人员汇总及顶卡按人/场次去重，避免同场多平台或兼任角色重复计时；没有时长明确提示未记录。
- 运营页不请求工资台账、移除时薪和时间工资及重复合计；CSV改为运营提成明细，导出直播分钟及原始起止/产品，不含时薪/时间工资。主播/中控保留原计薪分钟与工资展示。
- 无迁移、不修改工资记录、提成金额、审核或结算算法，不操作生产业务数据。沿用本轮用户明确的修改后上线授权。

验证：typecheck、根目录npm test、web build通过；MySQL直播25项通过，覆盖真实秒级计算、跨日舍入、缺失时间、传统运营中控仍无小时工资且有120分钟；前端8项专项覆盖纯提成非零直播时长、多人/多平台去重、缺失提示、CSV及原主播多平台工资只一次。
