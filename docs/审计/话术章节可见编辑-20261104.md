# 话术章节可见编辑

用户授权：修改后上线。

## 变化

- 每章显示标题、字数、独立正文编辑区及空章占位，目录点击直接定位输入。
- 明确显示正在编辑的章节；按目录顺序组成全文，预览包含章节标题，复制仍只含纯正文。
- 光标处拆章、选中文字独立成章或移动到目标章节末尾，素材标注随原文调整。
- 删除章节前选择合并到上一章末尾、下一章开头或连同内容删除；应用目录和保存版本前不写服务端。
- 复用 body / outline / cues 与现有版本保存、权限和冲突保护，不新增数据库迁移。
- 输入区随正文及容器宽度变化自动增高，320、390 手机尺寸没有横向溢出，正文高度与内容高度一致。
