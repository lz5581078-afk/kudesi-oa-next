# 资料联动当前读更新（2026-11-05）

通用 `ResourcesService.patchData(..., currentRead=true)` 先用当前读取得行，再调用 TypeORM save。若事务旧一致性快照尚无这条并发新增的行，save 的存在性检查会误判为新增，随后以已有主键 INSERT，报 resource_records.PRIMARY 重复。

确定性交错：先在 REPEATABLE READ 事务中建立空资源快照，再由另一事务新建品牌；旧事务普通读不可见该行，当前读可见，立即调用 patchData。修复前稳定报 Duplicate entry（/tmp/upload-code-current-read-before.log）；修复后通过（/tmp/upload-code-current-read-after2.log，单项113ms）。不依赖随机定时、手填主键或高并发碰运气。

修复仅针对 currentRead=true：已知已存在的行直接按公司、资源类型、ID UPDATE，不经 save 的旧快照存在性判断；当前读刷新实体后照常维护引用、日志和版本。其他更新路径保持原行为。新增 resource-current-read.db.spec.ts。

此修复可独立拣选，不含聚水潭上传锁码的任何规则、字段或队列修改。无迁移或生产数据写入。
